# tomateOnLinux

Suporte no Linux para mesas digitalizadoras **TOMATE**, feito por engenharia reversa e sem nenhum código do fabricante.

| Modelo | Pasta | Estado |
|---|---|---|
| MTM-1106 (USB `08f2:6811`) | [`MTM-1106/`](MTM-1106/) | Funcionando: caneta com pressão e inclinação, mapeamento para um ou vários monitores, 12 botões configuráveis, GUI em PySide6 |

Cada pasta traz o driver em userspace, o app de configuração, a documentação do protocolo e as instruções de instalação.

> Projeto independente, sem vínculo com a TOMATE ou com o fabricante das mesas. Nenhum binário, código ou pseudocódigo do driver oficial é distribuído aqui.
